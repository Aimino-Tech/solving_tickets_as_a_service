Frequently Asked Questions

Everything you need to know about STAS.

How is STAS different from Plip or Open SWE?
STAS is open-source, self-hostable, and uses our proprietary AGI that outperforms GPT-5.5 by 50% on the XOR benchmark. We're cheaper per fix and include quality gates that block hallucinations and broken tests before PR creation.
What models does STAS support for self-hosting?
Self-hosted STAS works with any model your API key provides. The hosted cloud tier uses our proprietary AGI model, which delivers the best results.
Do I need to configure anything after installing?
Zero config. Install the GitHub app, label an issue stas:fix, and STAS handles the rest. No webhooks to set up, no YAML to edit.
Is my code safe on the cloud plan?
All agents run in isolated sandboxed environments (E2B in production). Code is used only to investigate and fix the issue, never stored or trained on. For maximum privacy, use the self-hosted option.
What happens if the AI generates a bad fix?
Every fix passes 6 quality gates before PR creation, including compilation checks, test verification, dead code detection, and hallucination scanning. If those fail, the fix is retried up to 3 times before escalating to a human.
Can I use STAS with private repositories?
Yes. The self-hosted plan is designed for private repos. The cloud plan also supports private repos with enterprise-grade sandbox isolation.
Can I cancel anytime?
Yes. No lock-in, no contracts. The self-hosted version is fully open-source and yours forever.
