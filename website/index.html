How It Works

From Issue to PR in 4 Minutes

No config files. No YAML pipelines. Just label and go.

🔖

Label the Issue

Add the stas:fix label to any GitHub issue. STAS picks it up automatically via webhook.

🔍

Investigate

STAS reads the issue, explores your codebase, reproduces the bug, and identifies the root cause.

⚡

Fix & Verify

The OpenCode agent writes the fix, adds regression tests, and runs your test suite to verify.

🔄

PR Created

A draft PR appears on your repo with the fix, test results, and a full audit trail. You review and merge.
