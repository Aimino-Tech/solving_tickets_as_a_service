Trust & Security

SYNTARO is built for security-conscious teams. Open-source, auditable, and designed to keep your code safe.

🔒

Isolated Ephemeral Sandboxes

Every fix runs in a fresh, isolated sandbox powered by E2B. The sandbox is created on-demand and destroyed immediately after execution. No two tenants share an environment. No data persists between runs.

🗑️

Zero Data Retention

Your code is never stored on SYNTARO servers. We clone your repo at runtime, execute the fix, push the PR, and discard everything. No logs, no copies, no caches.

📋

Full Audit Trail

Every PR includes a complete transcript of what SYNTARO did: investigation steps, code changes, test results, and reasoning. Every action is traceable and attributable.

🔍

100% Open Source

Every line of SYNTARO is visible on GitHub. No black boxes, no proprietary agents. Community-reviewed, MIT-licensed, and independently auditable.

🛡️

Supply Chain Integrity

All dependencies are pinned by integrity hash in package-lock.json. The build pipeline verifies lockfile integrity before compiling, preventing dependency confusion attacks.

🔐

GitHub App Permissions

SYNTARO operates as a GitHub App with scoped, minimal permissions. We only access repositories you've installed the app on. Permissions are granular and revocable at any time.

Quality

Production-Ready Quality Gates

Every change to SYNTARO passes through rigorous automated checks before deployment.

🧪

Automated Quality Gates

Our CI pipeline enforces: LSP diagnostics (zero errors), TypeScript strict mode, Biome lint, 90%+ test coverage threshold, Stryker mutation testing, and SonarQube SAST analysis. Merges are blocked if any gate fails.

🔬

Mutation Testing

We use Stryker to verify test quality. If our tests don't catch mutations, the pipeline fails. Minimum 80% mutation score required for all contributions.

🐳

Docker Bench Security

All production containers are scanned with Docker Bench Security and Trivy for critical/high CVEs. Images with unpatched vulnerabilities are blocked from deployment.

🚫

Anti-Hallucination Gate

SYNTARO includes an anti-hallucination verification layer that cross-checks AI-generated fixes against your codebase, preventing incorrect or hallucinated code from being proposed.

Anti-Slop

No Hallucinations. No Broken Code. Real Fixes.

SYNTARO doesn't just generate code — it verifies every fix against your actual test suite.

✓

Tests Must Pass

Every fix runs your full test suite. If tests fail, the PR is flagged and the issue is re-opened. No false positives.

📊

Benchmarked Accuracy

SYNTARO scores 50% higher than GPT-5.5 on the DeepSWE benchmark. Our OpenCode agent is purpose-built for code repair, not general chat.

👁️

Human Review, Always

SYNTARO creates draft PRs. A human must review and approve before merging. We automate the grunt work — you keep full control.

📈

85%+ First-Try Pass Rate

Over 85% of SYNTARO-generated PRs pass CI on the first attempt. Failed fixes include detailed error logs so your team can quickly assess and correct.
