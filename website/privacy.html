Privacy Policy

Effective: July 30, 2026

1. Information We Collect

STAS collects only the minimum data needed to operate the service:

  • GitHub account information — username, avatar, email (via GitHub App installation)
  • Repository metadata — issue titles, descriptions, labels, comments, and code diffs
  • Usage data — fix run timestamps, status, and error logs
  • Billing information — for paid plans, handled by our payment processor (we do not store full payment details)

2. How We Use Your Data

We use collected data solely to:

  • Process fix requests on labeled GitHub issues
  • Display run history and analytics in your dashboard
  • Improve STAS accuracy and reliability
  • Send service notifications (fix completed, error reports)

We do not sell personal data, train models on your code, or share repository contents with third parties.

3. Data Retention

Fix run logs and issue data are retained for 90 days. Dashboard analytics are retained for 12 months. You may request deletion of your data at any time by contacting privacy@aimino.io.

4. Data Security

We implement industry-standard security measures:

  • Encryption in transit (TLS 1.3) and at rest (AES-256)
  • Minimal OAuth scopes (Contents: write, Issues: read, Metadata: read)
  • Regular security audits and dependency scanning
  • Access controls on production infrastructure

5. Third-Party Services

STAS integrates with:

  • GitHub — for issue tracking, code access, and PR creation
  • OpenCode — for AI-powered fix generation
  • Fly.io — for hosting the STAS website

Each service operates under its own privacy policy. We do not transfer data beyond what is necessary for service operation.

6. Your Rights

Depending on your jurisdiction, you may have the right to:

  • Access personal data we hold about you
  • Request correction or deletion of your data
  • Object to or restrict processing
  • Data portability

To exercise these rights, contact privacy@aimino.io.

7. Changes to This Policy

We may update this policy from time to time. Material changes will be announced via the STAS website or GitHub releases.

8. Contact

For privacy-related inquiries: privacy@aimino.io
