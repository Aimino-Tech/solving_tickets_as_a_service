SYNTARO Integrations

All supported agent platforms and how to connect. SYNTARO is designed to work with every major AI coding agent.

AI Coding Agents

OC

OpenCode Live

SYNTARO is built on OpenCode. Add it as a skill or plugin for seamless integration.

npx skills add Aimino-Tech/solving_tickets_as_a_service
OpenCode Skills → AGENTS.md →
CD

Claude Desktop Live

Configure SYNTARO as an MCP server in Claude Desktop for interactive issue fixing.

{
  "mcpServers": {
    "syntaro": {
      "command": "npx",
      "args": ["-y", "@aimino/syntaro-mcp"]
    }
  }
}
Install from Smithery → npm Package →
CR

Cursor Live

Add SYNTARO as an MCP server in Cursor's config for AI-powered issue resolution.

// .cursor/mcp.json
{
  "mcpServers": {
    "syntaro": {
      "command": "npx",
      "args": ["-y", "@aimino/syntaro-mcp"]
    }
  }
}
