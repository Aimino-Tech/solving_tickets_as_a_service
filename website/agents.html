Agent-to-Agent Discovery Loop

One-Line Install Per Agent Type

OpenCode

Add STAS as an OpenCode skill:

npx skills add Aimino-Tech/solving_tickets_as_a_service

Or add to opencode.json:

{
  "name": "stas-agent",
  "transport": "stdio",
  "command": "python",
  "args": ["-m", "mcp.stas_mcp", "stdio"]
}
Claude Desktop

Add MCP server to Claude:

{
  "mcpServers": {
    "stas": {
      "command": "npx",
      "args": ["-y", "@aimino/stas-mcp"]
    }
  }
}

Or install from Smithery.

Cursor

Configure in .cursor/mcp.json:

{
  "mcpServers": {
    "stas": {
      "command": "npx",
      "args": ["-y", "@aimino/stas-mcp"]
    }
  }
}
Codex CLI

Use via npm/npx:

npx -y @aimino/stas-mcp

Or add as a GitHub Action.

Auto-Discovery Features

MCP Registry

Published to the Model Context Protocol registry. Any MCP-compatible agent can discover STAS via .well-known/mcp/server-card.json.

Smithery.ai

One-click install from Smithery. Agent discovers → clicks install → STAS is active. No config files needed.

skills.sh

Published as a skills.sh skill. OpenCode and OpenClaw agents can auto-install with a single skills add command.

npm Registry

Published as @aimino/stas-mcp. Any agent with npm access can install and run STAS as a stdio MCP server.

Well-Known Discovery

STAS serves /.well-known/mcp-server-card.json for automatic agent detection across the web.

Agent Badge

Repos using STAS can display the "Agent Found STAS" badge, creating a viral discovery loop.
