### 2. copywriting-prose-creator (samber)
**Purpose:** Codify how a brand writes — prose mechanics (lexicon, syntax, rhythm, structure)
**Output:** PROSE.md file
**Three modes:**
- BUILD: Create fresh guide from SOUL.md + TONE.md
- ADAPT: Adapt existing guide to new channel
- AUDIT: Analyze corpus for prose patterns

**Why we need it:** Create consistent voice across all Aimino social media

### 4. humanizer (already installed ✅)
**Purpose:** Strip AI-isms and add real voice
**Key techniques:**
- Use "I" and "my" (first person)
- Have opinions (don't just report)
- Vary sentence length
- Acknowledge complexity
- Remove AI tells (emojis, bold headers, rule of three)

**Why we need it:** Make our comments sound human, not bot-generated

## 📥 How to Install These Skills

Most of these are available as ZIP downloads from mcpservers.org. To install:

1. Go to https://mcpservers.org/agent-skills
2. Search for the skill name
3. Click "Download ZIP"
4. Extract to ~/.hermes/skills/

Or use the skill_manage tool to create custom versions based on the descriptions.
