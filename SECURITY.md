# Security Policy

STAS takes security seriously. Please report vulnerabilities privately so they can be fixed before public disclosure.

The full security policy, threat model, and vulnerability response process live in [docs/SECURITY.md](docs/SECURITY.md).

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest release | ✅ |
| previous release | ✅ |
| older releases | ❌ |

## Reporting a Vulnerability

**Do NOT open a public issue for security vulnerabilities.** Use one of:

1. **GitHub Private Vulnerability Reporting** — on the [Security tab](https://github.com/Aimino-Tech/solving_tickets_as_a_service/security/advisories) (preferred).
2. **Email** — [security@aimino.com](mailto:security@aimino.com), or [tam@aimino.com](mailto:tam@aimino.com).

You will receive an acknowledgment within 48 hours and a timeline for the fix. We practice coordinated disclosure.
