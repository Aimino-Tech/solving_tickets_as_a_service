## The 9 deliverables (playbook sections)

1. Signal Hierarchy (Tier 1–5)
2. Source Map — 6 discovery channels ranked by signal purity
3. Reddit Research Protocol (Methods A–D)
4. 1–3★ Review Mining Protocol
5. 48h Validation Pass Runbook (<$100, reference cost ~$1.25)
6. Scoring Matrix — from ~200 complaints to 3 niches
7. Shadow Launch Validation Template (<$100, <72h)
8. Crowded-Market Playbook (Granola case)
9. Strategy-to-Source Mapping

## Framework flow

```
Signal (Tier 1–5) → Source channels → Reddit protocol → Review mine
        → 48h pass (6 gates) → Scoring matrix (G1–G7 + weighted ≥70)
        → Shadow launch (≥15% cold→waitlist) → BUILD pipeline
```
