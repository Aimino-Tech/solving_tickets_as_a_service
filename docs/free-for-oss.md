# Free for Open Source

STAS is **free for public open-source repositories**. We believe open source
should have access to the best tooling, including AI-powered issue resolution.

## What's Included

- Unlimited fixes on public repositories
- All pipeline templates (bug fix, feature, refactor, security audit)
- PRs with full fix narratives and test verification
- Priority in the fix queue

## Why Free for OSS

Every PR STAS generates includes a "Powered by STAS" footer. This is our
viral loop: great fixes on OSS repos → developers see STAS → more installs →
more fixes. It works because STAS is valuable enough that developers want
to share it.

## How It Works

When STAS is installed on a public repository and `free_for_oss: true`
is set in `.stas/stas.yml`, all fixes are processed at no charge.
