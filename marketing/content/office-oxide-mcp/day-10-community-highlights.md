**Tweet 2/5**
Community Project Spotlight: Document Q&A System

A developer built a RAG pipeline where office-oxide-mcp extracts text from 1,000+ DOCX contracts → chunks → embeds → vector search → Q&A.

The agent reads contracts via MCP, indexes them, and answers complex queries about terms, dates, and clauses. All self-hosted, all private.

**Tweet 3/5**
Community Project Spotlight: Automated Report Generator

A fintech team wired office-oxide-mcp into their data pipeline:
1. SQL queries → JSON aggregation
2. office-oxide-mcp writes formatted XLSX
3. Agent generates summary email with attachments

Replaced a $200/mo reporting SaaS with a single Rust binary.

**Tweet 4/5**
Community Project Spotlight: Batch PPTX Converter

A content agency migrated 500+ PowerPoint decks to HTML for their new website. office-oxide-mcp + a Python script handled the entire batch in under an hour.

Previously quoted cost: $5,000 to an agency. Actual cost: server time (~$0.50).
