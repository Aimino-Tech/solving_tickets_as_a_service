**Tweet 1/6**
Two weeks since launching office-oxide-mcp. Here's what happened, what I learned, and what's next. 🧵

**Tweet 2/6**
By the numbers:
⭐ 85+ GitHub stars
📦 400+ npm downloads
🔄 3 community PRs merged
💬 Active discussions on X, Reddit, and Discord

Not bad for a niche MCP server for Office document processing.

**Tweet 3/6**
What surprised me:
• Data pipeline use case grew fastest — people using it to extract Excel data for AI analysis
• Rust performance resonated more than expected — "sub-millisecond parsing" is our most-retweeted stat
• Self-hosted/private angle is the #1 selling point for enterprise users

**Tweet 4/6**
What I'd do differently:
• Launch with PDF support (most requested, took a week to add)
• More benchmark data upfront (numbers convert better than features)
• Submit to MCP directories on day 0, not day 5

All lessons applied to future launches.

**Tweet 5/6**
Roadmap for the next month:
• PDF read/write support (in progress)
• Document template engine
• Streaming read for large XLSX (500MB+)
• Google Docs ↔ Office bridge
• MCP directory listings (already submitted to 6 directories)
