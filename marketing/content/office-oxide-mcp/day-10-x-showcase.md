**Tweet 2/6**
@user1 built an invoice automation bot:
- Watches email for PDF invoices
- office-oxide-mcp extracts line items
- Matches to POs in Excel
- Generates approval Word doc
- Auto-replies with status

Processing 200 invoices/day. Zero human touch on standard invoices.

**Tweet 3/6**
@user2 built a contract analysis pipeline:
- New contracts land in a watched folder
- office-oxide-mcp extracts all clauses
- Agent scores risk per clause
- Summary Excel sheet auto-generated
- Legal team reviews only flagged items

First pass review: 100% automated. Human review: 80% faster.

**Tweet 4/6**
@user3 automated their weekly reporting:
- 12 data sources → SQL → agent
- office-oxide-mcp creates 3-section Word report
- Auto-inserts data tables and charts
- PDF output emailed to stakeholders

"Used to take all Friday. Now it runs Sunday night while I sleep."

**Tweet 5/6**
@user4 built a document QA system:
- Generated reports go through office-oxide-mcp
- Agent reads the output, checks for consistency
- Flags missing sections or incorrect data
- Auto-regenerates before delivery

Self-reviewing document pipeline. Agent creates, reviews, and fixes its own output.
