Build of the Week: Legal Document Analyzer
A solo lawyer built a contract review system:
- Watches a Dropbox folder for new PDF contracts
- office-oxide-mcp extracts clauses and dates
- An agent flags non-standard terms against a playbook
- Results logged to an Excel summary sheet

Saved 15+ hours of first-pass review in the first week alone.

**Tweet 3/6**
Build: Financial Report Automator
A fintech startup automated their investor reporting:
- SQL pulls metrics from production database
- office-oxide-mcp creates formatted XLSX with multiple sheets
- Agent generates summary DOCX with narrative
- Both files emailed to investors via SMTP

Replaced a $500/mo reporting tool. Runs on a $10 VPS.

**Tweet 4/6**
Build: Academic Paper Parser
A PhD student processing 200+ research papers:
- PDFs dumped into a folder
- office-oxide-mcp extracts text, tables, references
- Agent categorizes by topic and methodology
- Results stored in a searchable XLSX database

What would have taken 2 months of manual work completed in 3 days.

**Tweet 5/6**
Build: Invoice Processing Pipeline
A freelancer automated their invoicing:
- Client sends PDF invoice via email
- Agent extracts line items with office-oxide-mcp
- Matches against project budget in Excel
- Generates payment approval DOCX
- Archives everything organized by month

From 45 minutes per invoice to zero. The agent handles it end-to-end.
