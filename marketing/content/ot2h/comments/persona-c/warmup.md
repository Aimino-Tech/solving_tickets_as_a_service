### 1. [r/ClaudeAI] Helpful Claude features
**Context:** Features in Claude that new users might not know about.

Just discovered Claude can read images and it changed how I use it. Screenshot a bug, paste it in, Claude explains what's wrong. Game changer for debugging. Also the project knowledge feature is great for keeping context between conversations.

### 2. [r/selfhosted] First self-hosting experience
**Context:** Sharing stories about getting started with self-hosting.

Spent my weekend setting up a self-hosted monitoring stack. Grafana + Prometheus on a Raspberry Pi. Half the time was troubleshooting config files, the other half was admiring the dashboards. My server temps have never looked so good.

### 3. [r/coolgithubprojects] Discovering new repos
**Context:** How people find interesting GitHub projects.

I browse GitHub trending every morning with my coffee. Found so many useful tools that way. Sorting by "most stars this week" surfaces stuff I'd never find otherwise. The MCP ecosystem especially has been popping off lately.

### 4. [r/LocalLLaMA] Running models on modest hardware
**Context:** Running LLMs on laptops or older hardware.

Got a local model running on my 2021 laptop with 16GB RAM. Not breaking any speed records but it works. For tinkering and learning it's more than enough. You don't need a $5000 GPU setup to start playing with this stuff.

### 5. [r/webdev] Learning modern CSS
**Context:** The state of CSS in 2026 and what's worth learning.

Took a deep dive into CSS grid and container queries this month. Makes layout design so much easier than the float-based madness I learned years ago. CSS has gotten genuinely good. Grid + flexbox + container queries handles basically everything.

### 6. [r/ClaudeAI] Conversation quality tips
**Context:** Getting better results from Claude conversations.

I started adding context about what I've already tried before asking Claude for help. Makes the answers way more useful. Instead of "how do I do X" it's "I tried Y and Z, neither worked because of A, any other ideas?" Huge difference in output quality.

### 7. [r/selfhosted] Automating home tasks
**Context:** Fun automation projects for personal use.

Set up a script that checks the weather every morning and changes my smart light colors based on the forecast. Blue for rain, yellow for sun, grey for overcast. Completely useless but it makes me smile every day. Sometimes automation is just for fun.

### 8. [r/coolgithubprojects] Small but useful tools
**Context:** Simple tools that solve one problem well.

Found a CLI tool that converts between any data format. JSON to YAML, CSV to JSON, TOML to whatever. One command, no config file, just works. These single-purpose tools are my favorite kind of open source project. Solves exactly one problem and does it well.

### 9. [r/LocalLLaMA] Community model discovery
**Context:** How to find interesting models on Hugging Face.

Browsing Hugging Face models is overwhelming with how many there are. I started following the model cards that include benchmark results and example outputs. Way easier to make decisions. Also the community tab shows what people are actually running.

### 10. [r/webdev] Productivity in dev tools
**Context:** Browser dev tools tips and tricks.

Found out Chrome DevTools has a "Coverage" tab that shows which CSS and JS is actually used on your page. Ran it on a site I built and found 40% unused CSS from an old framework I thought I removed. Saved a bunch of page weight with one click.
