# Copywriting Guide for Social Media Engagement

## 🎯 Core Principles

### 1. Be Human, Not a Bot
- **Use "I" and "my"** — First person is honest, not unprofessional
- **Have opinions** — Don't just report facts, react to them
- **Vary sentence length** — Short punchy sentences mixed with longer ones
- **Acknowledge complexity** — Real humans have mixed feelings

### 2. The Anti-AI Checklist
Before posting, scan for these AI tells:
- ❌ "Great question!" / "Excellent point!" / "I hope this helps!"
- ❌ "Let's dive in" / "Let's explore" / "Here's what you need to know"
- ❌ Overuse of emojis (🚀, 💡, ✅, 🔥)
- ❌ Bold headers with colons ("**Speed:** ...")
- ❌ Rule of three ("innovation, inspiration, and insights")
- ❌ "Not only...but also" constructions
- ❌ "At its core" / "The real question is" / "What really matters"
- ❌ "serves as" / "stands as" / "represents" (just use "is")

### 3. Comment Formulas That Work

#### Formula 1: The Genuine Reaction
```
[Specific thing you liked] + [Your honest take] + [Optional: related experience]
```
**Example:** "The USB-C analogy for MCP is actually wrong — cables are passive, but MCP negotiates handshakes. We've been building MCP servers and the discovery part is what makes it different."

#### Formula 2: The Value-Add
```
[Agree with point] + [Add practical insight] + [Mention relevant work]
```
**Example:** "Spot on about the architecture knowledge being the real value. We found the same thing building opendocswork-mcp — the tool layer is easy, knowing when to use it is hard."

#### Formula 3: The Question That Shows You Know
```
[Observation about their post] + [Specific question] + [Why you're asking]
```
**Example:** "Interesting stack. How are you handling the MCP session management? We've been wrestling with that on our Office docs server."

#### Formula 4: The Story Fragment
```
[Relatable situation] + [What you learned] + [How it connects]
```
**Example:** "Spent last week debugging why our MCP server kept losing context. Turned out the session handling was the bottleneck. Your point about production readiness is spot on."

## 🎨 Tone Guidelines

### For Instagram Comments:
- **Shorter** — 1-3 sentences max
- **Casual** — Use contractions (don't, it's, we've)
- **Specific** — Mention exact tools/features, not vague praise
- **No emojis in comments** — Emojis scream bot

### For Threads Posts:
- **Conversational** — Write like you're talking to a friend
- **Opinionated** — Take a stand, don't hedge
- **Story-driven** — Share experiences, not just facts
- **Question-ending** — Invite engagement naturally

---

## ❌ Bad Examples (Looks Like a Bot)

```
"Great post! 🚀 I totally agree with your points about AI architecture. 
The future is bright for developers! Keep up the amazing work! 💡"
```

**Why it's bad:**
- Generic praise ("great post", "amazing work")
- Emoji spam
- No specific insight
- Sounds like every other bot comment

---

## ✅ Good Examples (Looks Human)

```
"This is actually wrong about MCP — cables are passive, but MCP 
negotiates handshakes. We built opendocswork-mcp and the discovery 
part is what makes it different from a simple API connector."
```

**Why it's good:**
- Disagrees respectfully (shows real thinking)
- Specific technical detail
- Mentions real work without being promotional
- No emojis, no exclamation marks

## 📝 Product Mention Rules

### DO:
- Mention products only when they're genuinely relevant
- Lead with the insight, not the product
- Use "we've been building..." not "check out our..."
- Make the mention feel like an aside, not the point

### DON'T:
- Start comments with product names
- Use "check out" / "look at" / "visit"
- Mention products in every comment
- Post the same product mention twice

### Good Mention:
```
"Your point about session management is real. We've been building 
MCP servers (opendocswork-mcp) and that's been our biggest challenge 
too — keeping context across long conversations."
```

### Bad Mention:
```
"Check out opendocswork-mcp! It's the best MCP server for Office 
docs. We built it to solve exactly this problem! 🚀"
```

## 🔄 Engagement Rhythm

### Daily Schedule:
1. **Morning (9-10 AM):** Find 3-5 relevant posts
2. **Midday (12-1 PM):** Leave 2-3 thoughtful comments
3. **Evening (5-6 PM):** Post 1 original thread/post

### Spacing:
- Don't comment on more than 3-5 posts per day
- Wait at least 30 minutes between comments
- Vary the types of posts you engage with
- Mix product mentions with pure engagement

## ⚠️ Red Flags to Avoid

1. **Same comment on multiple posts** — Instagram/Threads will flag this
2. **Commenting too fast** — Space out by 30+ minutes
3. **Only mentioning products** — Mix in pure engagement
4. **Using emojis excessively** — Looks automated
5. **Perfect grammar always** — Real people make typos sometimes
6. **Never disagreeing** — Always agreeing looks fake

---

## 🧠 Quick Reference Card

Before posting, ask:
1. Would I say this to a friend?
2. Does this add value to the conversation?
3. Am I being specific or generic?
4. Does this sound like a human wrote it?
5. Would I notice this comment if I saw it?

If you answered "no" to any of these, rewrite it.
